# ShareDL (Chaquopy)

Сборка: Android Studio → Open → Run. На машине сборки нужен Python 3.13
(или укажите свой в `chaquopy { defaultConfig { buildPython("...") } }`).
Python: yt-dlp + gallery-dl (pip, Chaquopy), ffmpeg-бинарник из youtubedl-android.
yt-dlp/gallery-dl обновляются из PyPI прямо в приложении (кнопка + раз в сутки).
